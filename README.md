# Instagram-Inspired Sign-Up UI | HTML & CSS

A static frontend recreation of a sign-up interface, developed to practise page structure, layout styling, and visual presentation.

> **Educational project only.** This is not affiliated with or endorsed by Instagram and does not provide Instagram authentication.

## Technologies
**HTML5 · CSS3**

## Interface Highlights
- Sign-up form layout with name, email/mobile, and password fields.
- Flexbox-based page layout.
- CSS styling for spacing, typography, colors, and alignment.
- Login and sign-up navigation elements.

## Development Focus
- Organizing page content with semantic HTML.
- Using CSS layout techniques to position interface elements.
- Building a consistent visual structure for a familiar sign-up experience.

## Run Locally
1. Clone or download this repository.
2. Open the project folder.
3. Open the HTML entry page in a web browser.

## Scope & Limitations
This is a static frontend exercise. It does not connect to Instagram, process credentials, or create user accounts.
